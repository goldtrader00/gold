Small print. "Contracts open" (open interest) = option contracts that exist and have not been closed; it is a map of where traders have positioned, not a buy/sell signal. "Far" in the watchlist = more than --scalp-range dollars away. Each zone is one GLD strike wide (about $11 of gold) and the conversion to gold prices can be off by roughly $5–15, so treat edges as approximate. Big ceiling / Big floor = my rule (zone at least 3× typical, or the biggest call/put level), not a trade signal. "Added overnight" = contracts added or removed since the last saved snapshot. The Smart Money score is an approximate reconstruction (0.7 × swap-dealer index + 0.5 × options premium skew), unvalidated; the options-flow card can be skewed by in-the-money puts after a drop, so I would ignore both. The gamma / speed reading assumes market makers are long calls and short puts, which is not verified. Use --full-table for extra columns (%, traded today, size in $).
